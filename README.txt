CRAVING HEAVEN — SIMPLE MOBILE-FRIENDLY MENU

Files:
- index.html : page layout + footer address
- style.css  : all design and responsive styles
- script.js  : cart, quantity controls, category navigation, delivery and call button
- menu.js    : MENU DATA — edit this file to change menu items, prices, descriptions, options and image filenames
- images/    : food and combo photos

MENU EDITING
Edit ONLY menu.js for:
- Item name
- Description
- Price
- Image filename
- Multi-price options

DELIVERY
- Below ₹300: ₹30 delivery
- ₹300 and above: FREE delivery

ORDERING
- Customer selects items and quantities
- Cart shows item total, delivery and final total
- Clear Cart is available
- Online ordering button is temporarily disabled and shows COMING SOON
- Customer can use the separate CALL NOW TO PLACE ORDER button

FOOTER ADDRESS
Edit the address directly in index.html if needed.

TESTING
Open index.html directly in Chrome for basic testing, or upload the whole folder to static hosting.

IMPORTANT
If you change a filename in menu.js, make sure the matching image exists in the images/<section>/ folder.
